Stockfish.js 19 (moteur d'analyse)
----------------------------------
La page télécharge et exécute, dans un Web Worker séparé, le moteur d'échecs
Stockfish compilé en WebAssembly par le projet Stockfish.js (version 19.0.1,
variante « lite single-threaded », fichiers non modifiés du paquet npm
« stockfish »).

  Fondé sur Stockfish (c) T. Romstad, M. Costalba, J. Kiiski, G. Linscott
  et autres contributeurs. Réseaux d'évaluation : Chris Bao (sscg13).

Stockfish est un logiciel libre : vous pouvez le redistribuer et le modifier
selon les termes de la licence publique générale GNU (GPL), version 3 ou
ultérieure, publiée par la Free Software Foundation. Il est distribué SANS
AUCUNE GARANTIE.

  Texte de la licence : /licences/GPL-3.0.txt
  Code source correspondant (version 19.0.1) :
    https://github.com/nmrugg/stockfish.js/tree/v19.0.1
  Projet d'origine :
    https://github.com/official-stockfish/Stockfish

Le code de cette page ne fait qu'échanger du texte (protocole UCI) avec le
moteur ; il est publié à part :
    https://github.com/SirAdaz/TowerDefense
